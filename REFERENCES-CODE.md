# Code references (IIE Harvard)

Every source file in this repository carries a `Reference scope` note that points here. Entries follow the
IIE Harvard style: *Author, Year. Title. [Online] Available at: URL [Accessed date].* Where one author has several
undated pages, the letters `n.d.a`, `n.d.b`, ... identify them, exactly as cited in the code comments.

> **Before submitting:** open each link once, confirm it still loads, and replace each blank access date
> (the underscores in the `[Accessed` brackets) with the day you checked it. `scripts/verify-submission.sh` fails while any blank remains. Entries already
> carrying a date were checked while preparing this release.
