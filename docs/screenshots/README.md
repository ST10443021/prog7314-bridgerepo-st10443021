# Screenshots to capture on the physical phone

Google Play needs 2 to 8 phone screenshots (JPEG or 24-bit PNG, each side between 320 px and 3840 px, long side at most twice the short side).
Take them from the **release build** on your own phone, with demo data and no real credentials visible, and save them here with these names so the README links work.

| File | Screen | What it proves |
|---|---|---|
| `play-01.png` | Sign-in with Google, GitHub and email | SSO |
| `play-02.png` | Biometric prompt over the unlock screen | Biometric authentication |
| `play-03.png` | Snippet Vault with folders and tags | User Defined 4 |
| `play-04.png` | Folders and Tags with a three-dot menu open | Rename and delete |
| `play-05.png` | Financial Tracker with the budget bar | User Defined 5 |
| `play-06.png` | Settings: sync switches and monthly budget | Settings saved to the API |
| `play-07.png` | Sync status with an offline queue, then synced | Offline mode |
| `play-08.png` | Notifications list with a budget alert or test push | Real-time notifications |
| `lang-af.png`, `lang-xh.png` | Any screen in Afrikaans and isiXhosa | Multi-language |

Tip: Android Studio > Device Manager > your phone > Screenshot, or hold Power + Volume Down on the phone.
